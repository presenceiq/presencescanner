About Code Blue Security

Code Blue Security is an owner-operated armed security company serving Englewood, Venice, Sarasota, North Port, and Port Charlotte, Florida, and has been protecting life and property for over 11 years. The company provides professional armed security for everything from private and residential situations to venues, special events, and customized security assignments. The owner is personally involved in operations and works in the field alongside the officers, so clients get hands-on service and accountability rather than a guard sent to fill a post.
